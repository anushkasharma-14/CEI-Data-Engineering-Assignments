# Week 5 - Apache Spark DataFrames

This repository contains my **Week 5** assignment completed as part of the **Celebal Technologies Data Engineering Internship**.

## Objective

The objective of this assignment is to understand the fundamentals of **Apache Spark** and perform data cleaning, transformation, filtering, aggregation, and analysis using **Spark DataFrames**.

## Tasks Performed

* Created a Spark Session
* Loaded a CSV dataset into a Spark DataFrame
* Explored the dataset by viewing records, schema, and columns
* Removed duplicate records
* Handled missing values using `.na.drop()` and `.na.fill()`
* Applied filtering based on different conditions
* Performed data transformation by modifying column names and data types
* Used aggregation functions such as `count()`, `sum()`, `avg()`, `min()`, and `max()`
* Grouped data using `groupBy()`
* Cleaned inconsistent records
* Built a simple data processing pipeline
* Understood concepts such as MapReduce, In-Memory Computing, DataFrame Immutability, and Shuffle Operations

## Files Included

* dataset.csv - Sample dataset used for performing Spark operations.
* spark.ipynb - Jupyter Notebook containing the complete implementation of all coding questions using PySpark.
* Week-5 Report.pdf - Report containing theory answers, code screenshots, outputs, and insights.
* README.md - Overview of the Week 5 assignment.

## Learning Outcomes

Through this assignment, I learned how to use Spark DataFrames for data processing, perform common data cleaning tasks, apply filtering and aggregation operations, understand DataFrame immutability, and build a simple end-to-end data processing pipeline using PySpark.
